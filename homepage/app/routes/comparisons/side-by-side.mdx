Ferrigura's checks compare every drawing in `compat` with Mermaid's to within 0.05 px. This page lets you look instead: nine everyday diagrams of medium size, each drawn from the same text by both. Each figure lays Ferrigura's drawing over Mermaid's: Ferrigura shows left of the divider, Mermaid right of it. Drag the divider by its handle or use the arrow keys to move between them.

## How the drawings were made

The drawings come from <Versions />, and nothing is touched up afterwards. Mermaid draws in headless Chromium; Ferrigura draws without a browser. Both get the configuration that the geometry check gives them, because Mermaid's defaults would change the look rather than the drawing: labels as SVG text instead of HTML, Ferrigura's bundled face and the `redux-color` theme, which is one of Mermaid's own.

<SharedConfig />

Ferrigura's drawings here use `{ compat: true }`, which draws Mermaid's geometry and colors for every diagram type. Ferrigura's default rendering (`compat: false`) draws its own look and layout instead; the [homepage](/#design-mode) shows it beside Mermaid's. Both drawings stand inline so the browser paints their text in the same context. Ferrigura's SVG embeds its font subsets; the page supplies the same face for Mermaid. Each figure links both files, and the diagram text opens below it.

## Where they differ

With `compat`, Ferrigura draws shared edge-label backgrounds at full opacity, so lines do not show through the text. This applies to flowchart, class, state and entity relationship diagrams. Each type keeps its theme's background color, including any explicitly configured transparency. Published Mermaid applies half opacity to some SVG labels, including flowcharts and state diagrams. This affects paint only, not layout.

The full-opacity correction is also applied to the pinned reference used by the geometry checks. This page shows the published Mermaid package unchanged.

## Render them yourself

`scripts/render-comparison.mjs` in the [homepage's sources](https://github.com/sebastian-software/ferrigura/tree/main/homepage) renders the current Ferrigura source and the published Mermaid package on macOS with `pnpm comparison:write`. The site's checks render Ferrigura's side again on every build and Mermaid's on macOS, where the geometry check runs too, because Chromium lays out text a little differently on Linux.
