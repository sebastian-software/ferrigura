# M6: the remaining P1 diagram types

M6 ports sequence, class, state, ER, gantt, timeline, gitGraph and journey, and the renderer of info: for each, the parser and its DB, the canonical model, the specs, and the renderer. The research per type is in `<type>/NOTES.md` (every rule cites the reference), the parser decisions and the quirks each port reproduces in `<type>/PLAN.md`.

**Done when** each type passes its ported specs, `pnpm port:diff <type>` shows no difference on every collected input, and `pnpm port:geometry <type>` is within tolerance on every comparable fixture. Fixtures are excluded only with a named reason, as in M5.

## Decisions

| Question         | Decision                                                                                                                                                                                                                                                                                                                                                                                  | Why                                                                                                                                                                                                       |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Themes           | Only `redux-color` and `redux-dark-color` ship. Any other theme name falls back to one of them, as since M2 (names ending in `dark` take the dark one). The branches some renderers take for a classic theme name (timeline, gitGraph) are not ported                                                                                                                                     | Decided by Sebastian on 2026-10-16 (decision 0007 stays as it is). The harness puts the fallback theme on both sides, so the reference draws the same branch and the comparison still covers the geometry |
| Quirks           | Each port reproduces the reference's behaviour, its quirks and its errors included, and lists every quirk in its `PLAN.md`. An exception is named only where the reference produces garbage (NaN, a crash, a random value)                                                                                                                                                                | The compatibility promise: the same text renders the same diagram                                                                                                                                         |
| Shared renderer  | class, state and ER render on the unified renderer of M5 (`crates/ferrigura-render/src/unified/`), each with its own `getData`; their new shapes, markers, cluster kinds and the terminal-label passes go into that module                                                                                                                                                                | The reference shares `rendering-util/` the same way                                                                                                                                                       |
| Text measurement | Each renderer measures text where and how the reference does (`getBBox` of an element, `calculateTextDimensions` and its rounding, `getComputedTextLength`), with Chromium's rules from M5: run advances ceiled to 1/64 px, ascent and descent rounded with a tie going down after flooring the size to 1/100 px, float32 boxes                                                           | The layout must see the reference's numbers                                                                                                                                                               |
| Gantt time       | Dates are read in UTC. The current time is an explicit option (`now`), at parse time for the dates that take missing parts from the clock and at render time for the today marker; without it ferrigura takes the system clock. The differential and the harness run the reference under UTC with a fixed clock                                                                           | A server-side renderer must not depend on the machine's time zone; the reference depends on the browser's                                                                                                 |
| gitGraph ids     | Commit ids the user does not give are generated deterministically in the reference's format. The parser differential replaces auto ids by placeholders in order on both sides; the geometry harness instead has both sides draw them from the page's seeded random stream (a hidden test option, `RenderOptions::git_graph_seed`), so the ids, and the classes that carry them, are equal | The reference draws them from `Math.random`                                                                                                                                                               |
| Journey labels   | The default text placement (`fo`, HTML in a `foreignObject`) is drawn as SVG text with the HTML line breaking emulated                                                                                                                                                                                                                                                                    | Decision 0004                                                                                                                                                                                             |
| Interactivity    | Links stay as SVG `<a>`; callbacks, popup menus and JavaScript click handlers are dropped from rendering, their parse state stays in the model where the DB holds it                                                                                                                                                                                                                      | Decision 0001                                                                                                                                                                                             |
| Scripts          | Fixtures with text the bundled faces do not cover are excluded until fallback fonts exist                                                                                                                                                                                                                                                                                                 | Open since M2                                                                                                                                                                                             |

## Shared infrastructure

- `pnpm port:geometry <type>` compares any diagram's SVG with the reference's by structural keys (`tag.class[n]` paths below the root), with the forced appearance of M5, scale 1, and exclusions; `--self` checks the reference against a second render of itself, with a fixed clock and seeded random numbers (all types pass).
- `pnpm port:diff <type>` runs each type's exporter (the reference's real parser and DB) against `ferrigura-syntax`'s `canonical` example; `pnpm port:diff config` covers each type's configuration section.

## Stages

1. **Parsers**, one task per type in parallel: model, parser and DB, specs, differential.
2. **Renderers on the unified renderer**: class, state, ER (shapes `classBox`, `erBox`, the state shapes; cluster kinds; markers; terminal labels; each diagram's style sheet).
3. **Custom renderers**: sequence, gantt, timeline, gitGraph, journey, info.
