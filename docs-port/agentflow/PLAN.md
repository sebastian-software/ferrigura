# Agentflow (P3) parser: plan

Status: the parser, the DB and the model are ported, with the exporter, the differential (`pnpm port:diff agentflow`, `pnpm port:diff config`), and the specs. Not ported: the layout data (`getData`), the renderer, and the element mappings (decision Q-g below). Reference: `packages/mermaid/src` at `sebastian/port-p3`. Research: [NOTES.md](./NOTES.md), sections 2 to 5 and 8. Rules: [P2-PARSERS.md](../P2-PARSERS.md), [P3-PLAN.md](../P3-PLAN.md).

## 3. Reproduced quirks

The NOTES numbers are in brackets. Each one has an input in `cases.ts` or a spec.

- **Silent drops.** A line whose text has `direction TB`, `LR`, `BT`, `RL` or `TD` anywhere (in a label or a comment) is one direction token, and its text is dropped [Q1]. A `click ` line is one `CLICK` token, which is dropped [Q2]. A top-level `direction` statement does nothing [Q3].
- **Header.** `setDirection` maps `<` to RL, `^` to BT, `>` to LR, `v` to TB, `TD` to TB, and keeps `BR` [Q4].
- **Edge limit.** `maxEdges` (500 by default) is checked before each edge is pushed [Q16].
- **Keywords match whole words**: `flowers`, `classroom`, `styled`, `defaultX`, `endpoint`, `globalX` are identifiers. `end --> b` and `call --> b` are syntax errors [Q6].
- **`connectors` is never a vertex**, and an edge that names it is kept [Q7].
- **Shapes** are case-sensitive and checked against the registry before anything else (`No such shape`). A removed shape (`cylinder`, `doc`, `circle`, `doublecircle`, `stadium`, `odd`, …) raises `SHAPE_REMOVED` in the layout data, and an unsupported one `SHAPE_UNSUPPORTED`; the node keeps `roundedRect` [Q8, Q9].
- **Containers.** A repeated id merges its members into the first record and takes the last title and direction [Q11]. A node in two containers stays in the first [Q12]. A containment cycle is kept as edges [Q13]. A container's label keeps the label type of its text, and a container with no label has `markdown` as its label type. A member list keeps the strings of the body: nested container ids, connector ids, accessibility titles and a lone `;`. `uniq` drops blanks and repeats; a member named `__proto__` is never a repeat, and the member `hasOwnProperty` makes the next member a TypeError, so a container with both is a syntax error.
- **Global.** A `global` block takes the ids of its body out of every container, including those declared earlier, and it is no statement of its own.
- **Connectors.** A connector is a vertex with `isConnector` and a title (or its id); a second declaration keeps the first record and takes a non-empty title. A connector declared over a vertex replaces its record in place.
- **Links.** A solid link ends in `x` or `>` and starts with `--`; `-.-` is a dotted link with no text; `==>` and `~~~` are lexical errors. A link id (`e1@`) and the `-- text -->` form take the edge id and the label. The ids of edges are `L_<start>_<end>_<n>`, and the second edge of a pair is `_2` [Q14]. The length is the dash count less one, or the dot count, capped at 10 [Q15].
- **Edge semantic**: `sequence` for `-->`, `failure` for `--x`, `reference` for `-.-`.
- **A link follows a blank.** `node spaceList` is a statement of its own, so a link may follow the blanks: `a e1@--> b`. A `node shapeData` statement cannot be followed by blanks.
- **Lexer at the end of the text.** Jison reads the end with every rule of the state it is in, so an open `accTitle:`, `accDescr {`, callback, argument list or click gives one empty token there. An empty accessibility value is a token mid-text too.
- **The brace-blank rule.** The wrapper removes `[^\S\n]*` between every `}` and the line break after it, before the grammar sees the text.
- **Edges and linkStyle.** `linkStyle` takes a position as the NUM token's text, and that is an index only when it is a canonical decimal of an existing edge: `00` and `5` out of range are errors [Q5]. `linkStyle default interpolate` sets the interpolation of the edges created after it. A style with no `fill` gets `fill:none` once, for all its edges.
- **Metadata.** A single-line block is wrapped in braces; a multi-line one is read as it is, with a retry without its line-trailing commas. Prototype keys go at every depth [Q17]. A metadata value that is not an object spreads as the reference's spread does (an array by index, a string by unit, a number or boolean not at all), and `0`, `""` and `NaN` are not truthy.
- **Metadata on ids.** The metadata of a container id, of a connector, or of an edge id goes to that record and makes no vertex. A bare id that is an edge id makes no vertex either. `shape` in the metadata is resolved as an alias, then checked for case and registry membership; `label` replaces the text.
- **Labels and links** are sanitised with the strict `sanitizeText` (DOMPurify's subset), and a link with `formatUrl`. The security level is the default, so a click sets the class `clickable` and no callback [Q19].
- **Accessibility**: `setAccTitle` removes the leading blanks; `setAccDescription` removes the blanks after each line break.

## 4. Left out, and why

- **The layout data.** `getData`, its nodes, edges and colour slots, and the node and edge lists of the layout are read when the layout runs. They come with the renderer (stage 5 of P3). The layout's diagnostics are read from the model by `semantic::diagnostics`, which includes `CONTAINMENT_VIOLATION`.
- **Collapsed containers' edges.** The redirection of edges into a collapsed container is layout data (`getData`).
- **Callbacks.** At `securityLevel: loose` a click binds a callback. The parse takes no security level, so the port has none [Q19].
- **Element mappings and positions** [Q-g].
- **`inheritDir`.** The configuration does not set it, so a container's direction is the body's own.
- **Configuration.** The `init` hook's two keys (`flowchart.arrowMarkerAbsolute`, `layout`, Q21) are the renderer's.

## 5. Gates and results

Differentials: `tools/port/diff.ts agentflow` (287 inputs: the 209 collected from the fixtures, the spec literals and the docs, plus the explicit probes, 254 accepted by the reference, 0 differences); `tools/port/diff-config.ts` (agentflow 287 of 287 accepted, 0 differences); `tools/port/diff.ts flowchart` (783 inputs, 0 differences, after the scanner change).

The coordinator's fuzz runs are outside the repository: about 7000 generated documents in two modes (one biased to valid statements), with the reference and the port compared on acceptance and on every field of the model. All of them agree.

Specs: 13 test binaries in `crates/ferrigura-syntax/tests/agentflow_*.rs`, 267 tests ported from the 33 reference spec files, the 8 conformance pairs and the diagnostics vocabulary. 181 pass and 86 are ignored, with none failing. The ignored tests name their reason: the layout data (`getData`), the renderer, the mermaid API, the element mappings and source positions, the DB diagnostic store, and the reference's conformance runner (Q-f). The status table is `docs-port/STATUS.md`, refreshed by `tools/port/status.ts`.
