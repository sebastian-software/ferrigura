# ferrigura-venn

`ferrigura-venn` is the layout of `@upsetjs/venn.js` 2.0.0, the part that Mermaid's venn renderer reaches: the placement of the circles, the text centers and the minimizers of `fmin`. It is ported from the JavaScript bundle that Mermaid runs, and checked against the library on captured inputs.

This [Ferrigura](https://github.com/sebastian-software/ferrigura) implementation crate exposes an experimental API. The [`ferrigura` facade](https://crates.io/crates/ferrigura) provides the [supported Rust API](https://github.com/sebastian-software/ferrigura/blob/main/docs/decisions/0022-stable-public-api.md).
