# ferrigura-venn

`ferrigura-venn` is the layout of `@upsetjs/venn.js` 2.0.0, the part that Mermaid's venn renderer reaches: the placement of the circles, the text centres and the minimisers of `fmin`. It is ported from the JavaScript bundle that Mermaid runs, and checked against the library on captured inputs.

This crate is a part of [ferrigura](https://github.com/sebastian-software/ferrigura). Its API may change between versions. To render diagrams, use the `ferrigura` crate.
